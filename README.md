# برنامه‌ریز کشیک اینترن‌ها

یک صفحه وب ساده و فارسی برای موبایل که کشیک‌های بیمارستان را **عادلانه** بین گروه‌های اینترن تقسیم می‌کند.

## چه کار می‌کند؟

- تاریخ‌ها شمسی است و هفته از شنبه شروع می‌شود.
- اینترن‌ها را به گروه‌های تقریباً هم‌اندازه تقسیم می‌کند (الف، ب، پ، …).
- هر کشیک یک عدد «سختی» دارد. کشیک سخت‌تر امتیاز بیشتری دارد.
- برنامه طوری چیده می‌شود که:
  - تعداد کشیک گروه‌ها تا جای ممکن برابر (یا به نسبت نفرات) باشد؛
  - جمع امتیاز گروه‌ها تا جای ممکن نزدیک به هم باشد؛
  - هیچ گروهی دو کشیک پشت سر هم نداشته باشد و کشیک‌های هر گروه با فاصله پخش شود.
- همه چیز روی گوشی خودتان انجام می‌شود؛ هیچ اطلاعاتی به جایی فرستاده نمی‌شود و بدون اینترنت هم کار می‌کند.

## روش استفاده

1. **مرحله ۱:** تاریخ شروع و پایان و نوع کشیک (فقط شب، یا روز و شب) را انتخاب کنید.
2. **مرحله ۲:** تعداد کل اینترن‌ها و حداکثر نفر در هر گروه را بنویسید.
3. **مرحله ۳:** سختی کشیک‌ها را مشخص کنید: یکی از دکمه‌های «آسان / عادی / سخت / خیلی سخت / دلخواه» را بزنید و بعد روی کشیک‌ها بزنید. برای عدد دقیق، انگشت را روی کشیک نگه دارید.
4. در صفحه خلاصه «ساخت برنامه» را بزنید.
5. با «کپی متن برای تلگرام/واتساپ» برنامه را کپی و برای گروه بفرستید. اگر چیدمان را نپسندیدید «چیدمان دیگر» را بزنید.

ورودی‌ها روی همان گوشی ذخیره می‌شود. برای پاک کردن همه چیز «شروع از اول» را بزنید.

## برای توسعه‌دهنده

فقط HTML، CSS و جاوااسکریپت ساده؛ بدون فریم‌ورک و بدون مرحله ساخت. فایل `index.html` را مستقیم باز کنید.

اجرای تست‌ها:

```
node tests/run.js
```
